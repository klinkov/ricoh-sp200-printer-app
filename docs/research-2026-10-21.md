# RICOH SP 202SN — результаты разведки (2026-10-21)

## Окружение
- macOS 26.7.1 (Darwin 25.6), Apple Silicon, CUPS 2.3.4, clang есть, cmake нет, brew есть.
- Принтер сейчас НЕ подключён (ни USB, ни Bonjour). Драйверов Ricoh в /Library/Printers нет.
- В Homebrew core нет `pappl`; есть `jbigkit`, `ghostscript`, `libusb`. Формулы pappl для macOS — в tap `shawnz/printing`.

## Протокол (host-based, «DDST»): PJL + JBIG1 (ITU-T T.82)
Источники:
- https://github.com/revisitor/ricoh-sp100 — shell-фильтр `pstoricohddst-gdi` (Unlicense), в README явно указан SP 202SN.
- https://github.com/ankitsingh99/ricoh-universal-ddst-driver — C-фильтр `rastertoricohddst` (MIT), SP 200 серия, тестирован только SP 200, macOS заявлен.
- http://zhangtemplar.github.io/ricoh/ — SP 204SN на Linux тем же фильтром; на macOS не завелось из-за зависимостей.

Поток (строки CRLF):
```
<ESC>%-12345X@PJL
@PJL SET TIMESTAMP=YYYY/MM/DD HH:MM:SS
@PJL SET FILENAME=<file>
@PJL SET COMPRESS=JBIG
@PJL SET USERNAME=<user>
@PJL SET COVER=OFF
@PJL SET HOLD=OFF
-- на каждую страницу --
@PJL SET PAGESTATUS=START
@PJL SET COPIES=<n>
@PJL SET MEDIASOURCE=TRAY1
@PJL SET MEDIATYPE=PLAINRECYCLE
@PJL SET PAPER=A4
@PJL SET PAPERWIDTH=<px>
@PJL SET PAPERLENGTH=<px>
@PJL SET RESOLUTION=600
@PJL SET IMAGELEN=<байт JBIG>
<raw JBIG>
@PJL SET DOTCOUNT=<чёрные пиксели / 100>
@PJL SET PAGESTATUS=END
-- конец --
@PJL EOJ
<ESC>%-12345X
```
JBIG: `pbmtojbg -p 72 -o 3 -m 0` ≈ libjbig options 0x48 (HITOLO|VLENGTH), order 0x03 (ILEAVE|SMID), stripe 128 строк, 1 плоскость.
DOTCOUNT: в shell-версии делится на 100, в C-версии — чистый popcount. Нужно сверить на железе.
Разрешение 600 dpi; SP 200 серия заявляет 1200x600. Дуплекс ручной. Лотки: TRAY1 и ручной.

## Путь на macOS 26+
- PPD/CUPS-фильтры в CUPS помечены deprecated (apple/cups#5270); Apple их ещё исполняет, дата удаления не объявлена. HP уже рекомендует только AirPrint.
- Надёжный путь: Printer Application на PAPPL — локальный IPP-сервер, виден macOS как AirPrint/Bonjour-принтер; принимает PWG/URF raster, конвертирует в PJL+JBIG, шлёт на принтер по USB (libusb) или в сеть. Пример упаковки: https://github.com/shawnz/homebrew-printing
