# Этап 0a: протокол теста на железе

Принтер: RICOH SP 202SN, `192.168.1.60`. Итог записать в `docs/protocol.md` (раздел «Ещё не подтверждено»).
Сборка: `make tools`; бинарники в `build/tools/`. Переменные: `P=192.168.1.60`, `T=build/tools`.

## 0. Подготовка
```
make tools
tools/ddst-probe $P            # порты 80/515/631/9100, SNMP
mkdir -p /tmp/hw && cd /tmp/hw
```
Положить в лоток 1 чистую A4. Измерительная линейка (мм) под рукой.

### Снимок счётчиков (до/после каждого шага)
```
snap() { for o in 1.3.6.1.2.1.43.10.2.1.4.1.1 1.3.6.1.2.1.25.3.5.1.1.1 1.3.6.1.2.1.43.11.1.1.9.1.1; do
  snmpget -v1 -c public -t 2 -r 1 $P $o; done; curl -s http://$P/H02_Home_status.htm | grep -o '[0-9]\{4,6\}' | head -3; }
snap | tee before.txt
```
Веб-панель (`http://192.168.1.60/`, `H02_Home_status.htm`): «Общий счётчик» (на 2026-10-21: 9172; SNMP LifeCount 9219).

## 1. Тестовая сетка, транспорт 9100
```
$T/mkgrid > grid.pbm
$T/pbm2ddst -p A4 grid.pbm > grid.ddst
tools/ddst-send $P 9100 grid.ddst; echo exit=$?
snap > after1.txt; diff before.txt after1.txt
```
Критерии: страница напечатана; LifeCount и «Общий счётчик» выросли ровно на 1; принтер вернулся в idle(3).
Если 9100 не работает: `lpr`-подобная отправка по LPD 515, затем IPP 631 (порядок проб из §7 спеки); первый рабочий записать.

Измерить линейкой и заполнить:

| Параметр | Значение |
|---|---|
| Масштаб: 10 клеток по ширине (ожид. 100 мм) | |
| Масштаб: 10 клеток по высоте (ожид. 100 мм) | |
| Поле слева (край бумаги до рамки; ожид. 10 мм) | |
| Поле справа | |
| Поле сверху | |
| Поле снизу | |
| Рамка/квадрат обрезаны? (да/нет, где) | |
| Ориентация (квадрат 10x10 мм в левом верхнем углу) | |
| PAPERWIDTH x PAPERLENGTH, принятые принтером | 4961 x 7016 / другое: |

Если края обрезаны или масштаб не 100 % ± 0,5 мм, повторить с другой геометрией (кандидаты: 4960x7016, 4760x6736):
```
$T/mkgrid -w 4760 -h 6736 > g2.pbm
$T/pbm2ddst -p A4 g2.pbm > g2.ddst && tools/ddst-send $P 9100 g2.ddst
```
(`pbm2ddst` берёт PAPERWIDTH/LENGTH из размеров PBM; `-p` задаёт только имя PAPER.)

## 2. PAGESTATUS=START
Текущий поток шлёт START на каждую страницу. Отправить 2-страничное задание (две сетки подряд: склеить
`grid.ddst` без UEL/EOJ не получится — использовать `-c 2` для двух копий) и убедиться, что обе страницы вышли:
```
$T/pbm2ddst -c 2 grid.pbm > c2.ddst && tools/ddst-send $P 9100 c2.ddst
```
Записать: копии работают на принтере (да/нет), счётчик +2 (да/нет).

## 3. Эксперимент DOTCOUNT
Нужны страницы с чернотой 1 % и 50 % (создать PBM; например `mkgrid` + заливка, или `pbmmake`/`python3`).
Для каждой чернотой отправить оба варианта и фиксировать SNMP-счётчики до/после (по 10-20 страниц, чтобы
тонер сдвинулся хотя бы на 1 %; уровень тонера в целых процентах):
```
$T/pbm2ddst -d div100 dark.pbm > d100.ddst
$T/pbm2ddst -d raw    dark.pbm > draw.ddst
```

| Страница | Режим | Страниц | Тонер до | Тонер после | Принтер принял (да/нет) |
|---|---|---|---|---|---|
| 1 % | div100 | | | | |
| 1 % | raw | | | | |
| 50 % | div100 | | | | |
| 50 % | raw | | | | |

Решение: выбрать режим, при котором расход тонера пропорционален черноте. Если оба проходят — div100.

## 4. Тест отмены
Оборвать сокет посреди страницы (передать часть файла), затем дослать завершение:
```
snap > before4.txt
head -c 200000 grid.ddst | nc -w 5 $P 9100          # обрыв посреди JBIG
sleep 5; snmpget -v1 -c public $P 1.3.6.1.2.1.25.3.5.1.1.1   # статус
printf '@PJL SET PAGESTATUS=END\r\n@PJL EOJ\r\n\033%%-12345X' | nc -w 5 $P 9100
sleep 5; snap > after4.txt
tools/ddst-send $P 9100 grid.ddst                    # повторная печать
```
Критерий: принтер вернулся в Ready без перезагрузки, последующая печать работает.

| Шаг | Результат |
|---|---|
| Статус после обрыва | |
| Что вышло на бумаге (пусто/частично) | |
| Принтер ready после досылки EOJ+UEL | |
| Повторная печать прошла | |
| Нужна пауза N с (если без досылки зависал) | |

Политика отмены (§10 спеки): [досылка PAGESTATUS=END+EOJ+UEL | закрыть сокет и ждать N с].

## 5. Итог
Заполнить `docs/protocol.md`: рабочий транспорт, PAPERWIDTH/LENGTH и поля A4, режим DOTCOUNT, нужен ли START
на страницу, политика отмены. При расхождении обновить `src/ddst/paper.c`.
